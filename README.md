# Credit_card_fraud_detection
• Conducted Exploratory Data Analysis, correlation analysis, and class-imbalance analysis on credit card
transaction data, examining the target class, amount distributions, and fraud-related features to identify key trends
• After train-test-split in 80:20, applied Logistic Regression and Random Forest classifiers using class weight
and SMOTE to improve the fraud detection performance on highly imbalanced credit card fraud transaction data
• Evaluated and compared models using Precision, Recall, F1-score, ROC-AUC, PR-AUC, and confusion
matrices, analyzing the impact of different class-imbalance handling strategies on fraud detection performance
• Optimized the Random Forest pipeline using RandomizedSearchCV with 5-fold cross-validation, achieving
Precision = 0.86, Recall = 0.95, F1-score = 0.90, ROC-AUC = 0.99, and PR-AUC = 0.93 on the test set
